How it works

One question, then the answer.

  1. Ask Claude like you always do.

    Your message sends right away. tot never blocks Send or makes you wait to ask.

  2. Think first.

    If it looks like you’re handing over the thinking, tot holds the answer back and asks one question about how you’d start.

  3. Your thinking joins the chat.

    The answer appears, and tot puts your reasoning in Claude’s message box, asking it to check your approach and guide the next step. You decide whether to send it.

Most of the time, you won’t see tot at all. Already showed your work, asking what something means, or writing an email? tot stays out of the way. And Skip is always there.

Install

Set up in a minute.

  1. Clone the repo from GitHub, then run npm install in it.
  2. Copy .env.example to .env and add your ANTHROPIC_API_KEY.
  3. Run npm start. It starts tot’s question server and builds the extension.
  4. Go to chrome://extensions, turn on Developer mode, click Load unpacked, and choose extension/.output/chrome-mv3-dev.
  5. Open claude.ai and ask away.
